## ✨ Features

- **Personalized Itineraries**: Intelligent tour planning based on your specific interests (History, Architecture, Culinary, etc.).
- **Dynamic Content**: High-quality storytelling scripts generated by DeepSeek V3 and Gemini-2.0 via OpenRouter.
- **Modern UI**: A sleek, "Spotify-inspired" Glassmorphism interface with backdrop-blur effects.
- **Adaptive Themes**: Seamless support for Dark and Light modes.
- **Premium Audio**: High-quality neural text-to-speech using Microsoft Edge TTS (`edge-tts`).
- **Privacy First**: Clean architecture with a secure backend proxy for API keys.

## � Getting Started

### Prerequisites

- Python 3.9+
- An [OpenRouter](https://openrouter.ai/) API Key

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/houyc1217/ai_audio_tour_guide.git
   cd ai_audio_tour_guide
   ```

2. Create and activate a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Configure your API key in a `.env` file:
   ```env
   OPENROUTER_API_KEY=your_key_here
   ```

### Running the App

Start the FastAPI server:
```bash
python backend/app.py
```
Visit `http://localhost:8000` in your browser.

## 🛠️ Technology Stack

- **Frontend**: Vanilla HTML5, CSS3 (Glassmorphism), JavaScript (ES6+).
- **Backend**: FastAPI (Python) for API handling and static file serving.
- **AI Orchestration**: 
  - **Planner**: Gemini 2.0 Flash Exp (via OpenRouter) - *Fast itinerary generation*
  - **Narrator**: DeepSeek V3 (via OpenRouter) - *High-quality storytelling*
- **Audio**: Microsoft Edge TTS (`edge-tts`) - *Neural speech synthesis*
